# Локальна перевірка виправлення CI → GitOps

Дата: 07.09.2026. Це перевірка локального коду, не запуск GitHub Actions чи EKS.

Перевірено фактичний Python-блок із job `update-gitops` на тимчасових копіях
Deployment за допомогою bundled Python:

- image і APP_VERSION отримують однаковий source SHA; інший вміст незмінний;
- повторний запуск не змінює файл;
- відсутній backend, відсутній APP_VERSION або дубльований документ спричиняють
  помилку без запису файлу;
- вхід із CRLF успішно обробляється;
- активний workflow та його копія для здачі однакові;
- `git diff --check` не виявив whitespace-помилок.

Результат: PASS. Початкова CRLF-проба мала помилку тестової підготовки
(подвійне перетворення переносу рядків у Windows); після запису точних байтів
проба пройшла. Production-код через цю помилку не змінювався.

Не перевірено тут: повний YAML/actionlint, реальний push від GITHUB_TOKEN,
правила захисту main, публікацію нового образу та ArgoCD rollout.
Поточний kube context відповідає `trezor`, `eu-central-1`; це саме по собі
не підтверджує доступність API або активний стан кластера.
