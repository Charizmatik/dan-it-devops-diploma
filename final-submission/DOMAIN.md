# Домен, реєстратор і DNS

Цей документ фіксує фактичну конфігурацію домену дипломного проєкту станом на
4 вересня 2026 року. Він не містить паролів, кодів підтвердження, номера
телефону, реквізитів картки або інших секретів.

| Дата створення | 4 вересня 2026 року, 21:30:05 |

Домен зареєстровано безкоштовно. Для активації PP.UA було підтверджено email і
номер телефону через реєстровий сервіс. Оскільки SMS не надійшло, код отримано
через офіційний Telegram-бот. Сам код у документації не зберігається.

NIC.UA також вимагав підтвердження платіжної картки операцією на 1 гривню.
Перевірку виконано, але жодних реквізитів картки в проєкті немає.

## Керування DNS

Спочатку домен використовував «Паркові NS». Для власних DNS-записів його
переведено на «Сервери імен NIC.UA»:

```text
ns10.uadns.com
ns11.uadns.com
ns12.uadns.com
```

| Параметр DNS-сервісу | Значення |
| --- | --- |
| Номер замовлення NS у NIC.UA | `2844029` |
| Дата створення NS-сервісу | 4 вересня 2026 року, 21:55:44 |
| NS-сервіс дійсний до | **4 грудня 2026 року** |
| Автопродовження NS-сервісу | вимкнено |

> Важливо: строк NS-сервісу коротший за строк домену. Його потрібно продовжити
> до 4 грудня 2026 року або заздалегідь перенести DNS на іншого провайдера.
> Інакше домен залишиться зареєстрованим, але DNS-записи можуть перестати
> обслуговуватися.

Шлях у панелі NIC.UA:

```text
Особистий кабінет → Домени → mikoladolia.pp.ua → Налаштування
→ Налаштування DNS-записів → Змінити DNS-записи
```

## Запис ArgoCD

```text
Ім'я:  argocd
TTL:   3600
Тип:   CNAME
Дані:  a1c1c754f56d9462b8b7de20717f5220-fbf34f3104150947.elb.eu-central-1.amazonaws.com.
```

Повне ім'я та URL:

```text
argocd.mikoladolia.pp.ua
http://argocd.mikoladolia.pp.ua
```

HTTPS-сертифікат поки не налаштовано, тому перевірений URL використовує HTTP.
Публічний Google DNS підтвердив CNAME, а прямий HTTP-запит повернув `200 OK` і
сторінку з title `Argo CD`.

## Запис застосунку

5 вересня 2026 року для четвертого етапу створено запис:

```text
Ім'я:  app
TTL:   3600
Тип:   CNAME
Дані:  a1c1c754f56d9462b8b7de20717f5220-fbf34f3104150947.elb.eu-central-1.amazonaws.com.
```

Повне ім'я та перевірений URL:

```text
app.mikoladolia.pp.ua
http://app.mikoladolia.pp.ua
```

Авторитетний NS і Google DNS повернули цей CNAME. Публічний HTTP-запит
повернув `200 OK` та JSON з IP фактичного pod.

## Інші записи, створені NIC.UA автоматично

Під час створення NS-сервісу NIC.UA додав стандартні записи. Вони не
використовуються дипломним застосунком і не керуються Terraform:

| Ім'я | TTL | Тип | Дані |
| --- | ---: | --- | --- |
| `@` | 14400 | A | `135.181.41.169` |
| `www` | 14400 | A | `135.181.41.169` |
| `mail` | 14400 | A | `135.181.41.169` |
| `ftp` | 14400 | CNAME | `mikoladolia.pp.ua.` |
| `@` | 14400 | MX | `mail.mikoladolia.pp.ua.`, priority `10` |

Не видаляти ці записи без окремого рішення: хоча зараз вони не потрібні
проєкту, видалення змінює поведінку кореневого домену та стандартних
піддоменів.

## Зв'язок із Terraform та AWS

- AWS region: `eu-central-1` (Frankfurt).
- EKS cluster: `trezor`.
- ArgoCD працює як Kubernetes workloads у namespace `argocd`, а не як окремий
  EC2 instance.
- Вхідний трафік проходить через спільний ingress-nginx Network Load Balancer.
- У поточному AWS-акаунті немає Route53 hosted zone для цього домену.
- У `terraform.tfvars` задано
  `argocd_hostname = "argocd.mikoladolia.pp.ua"`.
- `argocd_route53_zone_id = null`, тому Terraform не змінює DNS у NIC.UA.
- Terraform output `argocd_dns_target` повертає актуальну ціль для CNAME.

Якщо ingress-nginx Service або NLB буде видалено й створено повторно, його DNS
hostname може змінитися. Тоді потрібно виконати:

```powershell
terraform output -raw argocd_dns_target
```

Після цього вручну замінити значення CNAME `argocd` у NIC.UA і повторити
перевірку DNS та HTTP.

## Перевірка

```powershell
Resolve-DnsName mikoladolia.pp.ua -Type NS
Resolve-DnsName argocd.mikoladolia.pp.ua -Type CNAME
Invoke-WebRequest http://argocd.mikoladolia.pp.ua
kubectl get pods,service,ingress -n argocd -o wide
terraform output argocd_dns_target
```

Очікуваний результат: NS належать `uadns.com`, CNAME веде на поточний NLB,
HTTP повертає `200`, а основні pods ArgoCD мають стан `Running`.

## Доступ і безпека

- Обліковий запис NIC.UA належить власнику проєкту та використовує підтверджену
  email-адресу. Її не дубльовано в публічній документації.
- Пароль NIC.UA, початковий пароль ArgoCD, коди активації та платіжні дані не
  зберігаються в Git, Terraform або цій документації.
- Початковий пароль ArgoCD береться лише з Kubernetes Secret
  `argocd-initial-admin-secret` у namespace `argocd`.
- Після завершення роботи початковий пароль варто замінити власним. Зміна
  пароля виконується власником вручну й не повинна потрапляти у скріни.
